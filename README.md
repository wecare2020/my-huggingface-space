# Phuoc Hung ERP Refine Demo

Published ERP/process-app demo for Phuoc Hung manufacturing workflows.

## Live links

- GitHub repository: https://github.com/wecare2020/my-huggingface-space
- Git-hosted static preview: https://raw.githack.com/wecare2020/my-huggingface-space/main/index.html
- GitHub Pages URL, if Pages is enabled for this repo: https://wecare2020.github.io/my-huggingface-space/

## Features

- Dashboard process overview
- Orders table with search
- Production jobs
- Purchase requests
- QC checklist
- Quick create-order modal
- Responsive mobile layout

## Supabase / Refine source

The full React + Vite + Refine + Supabase-ready project was prepared locally in Codex. The Supabase SQL schema is in the Codex deliverable zip from the original project workspace.
